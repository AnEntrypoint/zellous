wireweave relay-pool.js netcode reliability (v0.3.24, 2026-06-21): RelayPool now has a _closed flag + _reconnectTimers Map. disconnect() sets _closed=true and clears all tracked reconnect timers so an in-flight setTimeout(_open) can no longer resurrect a relay after teardown (was a real bug: onclose scheduled reconnect, disconnect only cleared the relays map). connect()/heal() reset _closed=false. Reconnect backoff is jittered +-25% via jitter(ms)=round(ms*(0.75+rand*0.5)) to break lockstep thundering-herd reconnects. Offline publish queue (this.pending) stores {event,ts}, capped at PENDING_MAX=500 (drop oldest) with PENDING_TTL_MS=120000 drop-on-drain. Tests: test.js testRelayReconnectCancel + testRelayPendingCapTtl use a fake-WS impl; 26 tests pass.
