SDK C.ContextMenu (editor-primitives.js) clamps to viewport by positioning at anchor then re-clamping in requestAnimationFrame — clamping synchronously in the ref callback measures a zero-size box (children unpainted) and silently no-ops, so near-edge menus overflow. The rAF post-layout clamp is required. Item shape {label,danger,disabled,icon,onSelect,separator}; mount passes {items,anchor:{x,y},onClose}. Stale browser cache can mask SDK fixes — cache-bust (?cb=) + fresh playwriter session when a deployed SDK change seems not to take.
